About This Player

This is a custom-built music player made with plain HTML, CSS, and JavaScript — no frameworks, no build tools, just a straightforward audio player you can host anywhere for free.

Features: browse a scrollable song list, play/pause any track from the list or the main controls, skip forward and backward, drag the progress bar to seek, and see the currently playing track name update live.

Built and deployed with GitHub + Netlify, so every update pushed to the repository goes live automatically within a couple of minutes.
